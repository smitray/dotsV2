## Best Practices
- **DO** use clear, descriptive headers.
- **DO** use code blocks with language specifiers (e.g., `python`, `bash`).
- **DO** include a table of contents for long documents.
- **DON'T** use excessive formatting (bold/italic) unless necessary for emphasis.
